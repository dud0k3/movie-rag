# Что Киноархив взял из 10 сервисов поиска

Сравнение по публичной документации. У сервисов разные аудитории и способы считать использование, поэтому порядок отражает темы сравнения.

| Сервис | Что описано в источнике | Применение в Киноархиве |
| :-- | :-- | :-- |
| [Perplexity Pro Search](https://www.perplexity.ai/help-center/en/articles/10352903-what-is-pro-search) | Несколько поисков с последующим общим ответом и ссылками. | Один связный ответ по найденным частям вопроса. |
| [Google AI Mode](https://blog.google/products-and-platforms/products/search/ai-mode-search/) | Query fan-out запускает поиски по подтемам. | Составной вопрос запускает ограниченный набор локальных поисков. Для гибридного режима дополнительные запросы работают через BM25 без генерации. |
| [Microsoft Bing Deep Search](https://blogs.bing.com/search-quality-insights/2023/12/Introducing-Deep-Search/) | Расширяет запрос и предлагает уточнить его при нескольких трактовках. | При одноимённых фильмах выбор объекта остаётся у пользователя. Поиск фактов ограничен этим объектом. |
| [You.com Research](https://you.com/docs/guides/research) | Выбирает объём работы в зависимости от задачи, возвращает ответ с цитатами. | Лимит контекста и длина ответа зависят от типа вопроса. |
| [Kagi Quick Answer](https://help.kagi.com/kagi/ai/quick-answer.html) | Быстрая выжимка по результатам со ссылками. | Простые факты вроде имени композитора или числа сезонов извлекаются из каталога напрямую. |
| [Brave Search](https://search.brave.com/help) | Краткие ответы по результатам поиска с указанием источников. | Ответ начинается с искомого факта. При сбое модели доступны выдержки из источников. |
| [Google NotebookLM](https://blog.google/innovation-and-ai/products/notebooklm-goes-global-support-for-websites-slides-fact-check/) | Цитата открывает конкретное место в источнике. | Номер ссылки связан с карточкой и раскрываемым фрагментом. |
| [Grok Web Search](https://docs.x.ai/developers/tools/web-search) | Поисковый инструмент возвращает ссылки и поддерживает ограничения по доменам. | Источники ограничены каталогом TMDB и статьями Wikipedia, связанными с выбранным объектом. |
| [DuckDuckGo Search Assist](https://duckduckgo.com/duckduckgo-help-pages/results/ai-assisted-answers) | Короткий ответ с одной или двумя ссылками. | Один или два предложения для простого вопроса, ссылки рядом с фактами. |
| [Claude Research](https://support.claude.com/en/articles/11088861-use-research-on-claude) | Уточняет направление поиска по уже найденному материалу. | Поиск сначала ограничивает корпус, а затем отбирает фрагменты для каждой подтемы. На ответ приходится один вызов генерации. |

Результаты сравнения версий и моделей см. в [отчёте сравнения](../evaluation/cinema_depth_report.json).
