# Демо-видео и сценарий защиты

Файл `demo/movie-rag-demo.mp4` длится около 19 секунд. Он записан в отдельном браузере с работающим локальным сервером и Ollama. Ожидание генерации ускорено при монтаже.

В видео: начальный каталог из 100 фильмов → поиск «Интерстеллара» → выбор фильма → вопрос о режиссёре и создании → ответ Qwen на русском языке с номерами и ссылками на TMDB/Wikipedia.

Для более подробной живой защиты:

1. Откройте один источник справа и покажите, где подтверждён факт.
2. Переключите метод на **Только BM25**, затем **Только по смыслу** и сравните результаты `/search` в `/docs`.
3. Найдите нового человека, например **Christopher Nolan**, загрузите его и спросите о фильмографии.
4. Покажите GitHub README и `evaluation/results.json` с Recall@K.

Для защиты: источник данных → очистка текста → чанки → BM25 и эмбеддинги → объединение → Qwen3.5 → ссылки. Укажите, что при недоступной LLM включается выжимка из фрагментов.
