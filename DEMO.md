# Сценарий демо-видео

Ориентировочная длительность: 90–120 секунд. До записи запустите сервер и Ollama.

1. Покажите главную страницу и число загруженных фильмов.
2. Найдите **Interstellar** через верхнее поле и выберите фильм. Дождитесь сообщения о загрузке материалов.
3. Спросите: **«Кто снял фильм и что известно о его создании?»** Покажите ответ и ссылки на TMDB/Wikipedia справа.
4. Откройте один источник в новой вкладке, чтобы показать проверяемость ответа.
5. Вернитесь в приложение, переключите метод на **Только BM25**, затем **Только по смыслу** и покажите результаты `/search` в `/docs` или через отдельный запрос. Объясните разницу.
6. Найдите нового человека, например **Christopher Nolan**, загрузите его и спросите о фильмографии.
7. В конце покажите GitHub README с инструкцией запуска и результат Recall@K.

Для защиты: источник данных → очистка текста → чанки → BM25 и эмбеддинги → объединение → Qwen3.5 → ссылки. Укажите, что при недоступной LLM включается выжимка из фрагментов.
