## Что спросить

| Выберите в поиске | Задайте вопрос |
| :-- | :-- |
| 🎬 **Престиж** | Как Борден выполнял трюк с телепортацией? |
| 📺 **Слово пацана. Кровь на асфальте** | Кто такая Айгуль и как она связана с Маратом? |
| 🎭 **Джейсон Стейтем** | Каким видом спорта он занимался до кино? |

Можно выбрать фильм из каталога или указать точное название в кавычках. При совпадении названий выберите нужный год в меню. Первый выбор загружает доступные материалы, повторный использует локальную базу. Пока Qwen пишет ответ, он появляется по частям. После завершения можно открыть цитату и фрагменты, которые получила модель.

<a id="start"></a>
## Запуск

Нужны Python 3.11+, [ключ TMDB](https://developer.themoviedb.org/docs/getting-started) и интернет для первой загрузки материалов. Для генерации поставьте [Ollama](https://ollama.com/download).

```bash
git clone https://github.com/dud0k3/movie-rag.git
cd movie-rag
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

В `.env` заполните `TMDB_API_KEY` или `TMDB_READ_ACCESS_TOKEN`. В `WIKIMEDIA_CONTACT_URL` укажите ссылку на свой профиль или репозиторий. Файл `.env` исключён из Git. [Требования Wikimedia к User-Agent](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy)

```bash
ollama pull qwen3.5:9b
uvicorn movie_rag.app:app
```

**[Открыть Киноархив](http://127.0.0.1:8000/)** · [Swagger UI](http://127.0.0.1:8000/docs)

Запись демо сделана в браузере с локальным сервером. [Сценарий записи](scripts/record_demo.py)

При недоступной Ollama сервис выдаёт выдержки из материалов. Если энкодер недоступен, можно выбрать BM25 в меню «Метод». Предварительная загрузка всего каталога не требуется.

<a id="architecture"></a>
## Архитектура

```mermaid
flowchart LR
    Q[Вопрос] --> E[Фильм, сериал или человек]
    E --> S[TMDB и Wikipedia RU / EN]
    S --> DB[(SQLite)]
    DB --> R[BM25 и семантический поиск]
    R --> P[Ранжирование фрагментов]
    P --> M[Локальная Qwen3.5]
    M --> A[Ответ, ссылки и фрагменты]
    P --> F[Выдержки без модели]
```

1. **Идентификация.** Каталог различает фильмы, сериалы и людей. При поиске статьи учитываются название, тип объекта и год выпуска. Русская и английская статьи загружаются параллельно.
2. **Поиск.** Документы режутся на фрагменты примерно по 480 слов с перекрытием 80. SQLite FTS5 даёт BM25, многоязычный MiniLM ищет по смыслу, а взвешенный RRF объединяет ранги. После отбора чанков сервис выбирает отдельные места, сохраняя заголовки разделов и соседние предложения там, где они поясняют сцену.
3. **Ответ.** Для простых сведений из каталога, например имени режиссёра, предусмотрен прямой ответ. Для остальных вопросов выполняется один вызов локальной модели с коротким контекстом. Перед показом финального текста проверяются номера ссылок. Если источники не покрывают вопрос, сервис сообщает об этом.

Подход к поиску и переранжированию основан на идеях [Contextual Retrieval](https://www.anthropic.com/research/contextual-retrieval). Короткий контекст учитывает эффект, описанный в работе [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/). Для интерфейса использован знакомый паттерн ответов с нумерованными ссылками. [Perplexity](https://www.perplexity.ai/help-center/en/articles/10352895-how-does-perplexity-work)

## Проверка качества

**8 вопросов · MacBook Air M4 · Qwen3.5 9B · прогретая модель**

| Метрика | До ([`7f01b5f`](https://github.com/dud0k3/movie-rag/commit/7f01b5f)) | Текущая версия |
| :-- | --: | --: |
| Автоматические проверки ответа | 4/8 | **7/8** |
| В ответах на вопросы с известным ответом номера ссылок существуют | 7/7 | 7/7 |
| Все ожидаемые факты найдены в выбранных чанках | 7/7 | 7/7 |
| Поиск фрагментов, p95 | 0.38 с | **0.27 с** |
| Первый текст, p95 | 5.13 с | **5.04 с** |
| Готовый ответ, p95 | 10.89 с | **9.10 с** |

Для 6 ответов с доступной статистикой Ollama медиана составила **660 входных и 34 выходных токенов**. Имя режиссёра в контрольном вопросе получено без генерации.

Факты проверяются по заранее заданным выражениям. Эта проверка не оценивает каждое утверждение и не гарантирует, что цитата подтверждает весь ответ. В отчёте сохранены тексты ответов и URL, по которым их можно проверить вручную. Тест о планете Миллер требует явного упоминания гравитации. Текущий ответ называет чёрную дыру, но этого недостаточно для зачёта по заданному критерию. При восьми вопросах p95 соответствует самому медленному наблюдению. Холодная загрузка из сети измеряется отдельно.

```bash
python -m unittest discover -s tests -q
python -m evaluation.benchmark --prepare --output /tmp/cinema-benchmark.json
```

`--prepare` загружает недостающие объекты из текущих версий TMDB и Wikipedia. Содержимое источников и скорость могут меняться. [Вопросы и ожидаемые факты](evaluation/cinema_cases.json) · [Отчёт сравнения](evaluation/cinema_report.json)

**Границы покрытия.** Полный сюжет доступен там, где он опубликован в найденной статье. Для редких фильмов, отдельных эпизодов или биографий с малым количеством материалов ответ может быть частичным. Поиск материалов ограничен выбранным фильмом, сериалом или человеком.

<a id="api"></a>
## API

| Метод | Назначение |
| :-- | :-- |
| `GET /discover?q=...` | Подсказки по каталогу |
| `POST /ingest` | Загрузка объекта по типу и TMDB ID. `refresh: true` повторяет сбор |
| `GET /search?q=...&mode=hybrid` | Поиск по чанкам с оценками и URL |
| `GET /ask?q=...` | Ответ и источники. Для точного выбора передайте `entity_type` и `entity_id` |
| `GET /ask/stream?q=...` | Источники, части ответа и итог через NDJSON |
| `GET /health` | Готовность поиска и размер базы |

```bash
curl --get 'http://127.0.0.1:8000/ask' \
  --data-urlencode 'q=Какую таблетку выбрал Нео и что она ему позволила узнать?' \
  --data-urlencode 'entity_type=movie' \
  --data-urlencode 'entity_id=603'
```

Источники данных: [TMDB](https://www.themoviedb.org/) и [Wikipedia](https://www.wikipedia.org/). This product uses the TMDB API but is not endorsed or certified by TMDB.
