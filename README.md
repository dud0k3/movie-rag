<a id="architecture"></a>
## Как устроен Киноархив

```mermaid
flowchart LR
    S[TMDB и Wikipedia] --> DB[(Локальная база SQLite)]
    Q[Вопрос о фильме или актёре] --> R[Гибридный поиск]
    DB --> R
    R --> P[Фрагменты по частям вопроса]
    P --> M[Локальная Qwen3.5]
    M --> A[Ответ и источники]
    R -->|Точный факт из каталога| A
```

**Сбор и поиск.** Материалы загружаются при первом выборе фильма или человека. BM25 находит совпадения по словам, MiniLM — по смыслу. Для каждой части вопроса сервис отбирает свой набор фрагментов и сохраняет соседние предложения, если они объясняют сцену.

**Ответ.** Имена режиссёров, композиторов и другие точные поля можно получить сразу из каталога. Сюжет и биографию объясняет Qwen через Ollama. FastAPI отдаёт текст по мере генерации и связывает цитаты с карточками источников.

<a id="start"></a>
## Быстрый запуск

Установите Python 3.11+ и [Ollama](https://ollama.com/download). Для загрузки материалов понадобится [ключ TMDB](https://developer.themoviedb.org/docs/getting-started).

```bash
git clone https://github.com/dud0k3/movie-rag.git
cd movie-rag
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

В `.env` заполните `TMDB_API_KEY` или `TMDB_READ_ACCESS_TOKEN`. Для `WIKIMEDIA_CONTACT_URL` подойдёт ссылка на ваш профиль GitHub.

```bash
ollama pull qwen3.5:9b
uvicorn movie_rag.app:app
```

**[Открыть Киноархив](http://127.0.0.1:8000/)** · [Интерактивное API](http://127.0.0.1:8000/docs)

В API доступны загрузка материалов (`POST /ingest`), поиск фрагментов с оценками и ссылками (`GET /search`) и ответ с источниками (`GET /ask`).
